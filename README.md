# 🌦️ SkyFetch Weather Dashboard

A simple and interactive weather dashboard that allows users to search for real-time weather information using a city name.

---

## 🚀 Features

### ✅ Part 1: API Integration
- Fetches real-time weather data using an external API
- Displays:
  - Temperature 🌡️
  - Weather condition ☁️
  - City name 📍
- Handles invalid city inputs gracefully

---

### ✅ Part 2: User Interaction
- User can enter a city name in the input field
- Click on **Search button** to fetch weather
- Supports **Enter key press** for search
- Dynamic UI updates without page reload
- Basic input validation implemented

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Fetch API

## ⚙️ How It Works

1. User enters a city name
2. Application sends request to weather API
3. Receives JSON response
4. Updates UI with weather details
